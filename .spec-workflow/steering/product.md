# Product Vision

## Purpose
Open Anime Tracker is a full-stack web application for tracking and rating anime. Users can search for anime, view their details, add them to their collection, rate them, and track their progress.

## Target Users
- Anime enthusiasts who want to track their watched anime
- Users who want to rate and organize their anime collection
- People looking for a simple, personal anime tracking tool

## Key Features
- **User Authentication**: Sign up, sign in, session management
- **Anime Search**: Search the anime database
- **Anime Management**: Add, edit, delete anime entries
- **Anime Details**: View anime information including seasons and ratings
- **Kitsu Import**: Import anime data from Kitsu
- **Rating System**: Rate anime and individual seasons

## Principles
1. **Simplicity**: Clean, straightforward user experience
2. **Performance**: Fast loading and responsive interface
3. **Maintainability**: Well-organized, modular code following established patterns
4. **Progressive Enhancement**: Core features work without external dependencies
